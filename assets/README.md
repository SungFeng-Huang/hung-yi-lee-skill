# assets

Image assets referenced by the project README.

## hung-yi-lee.jpg

The portrait shown at the top of [`README.md`](../README.md) and [`README.en.md`](../README.en.md).

**To add it**: save the photo to this folder as exactly `hung-yi-lee.jpg`, then commit it:

```bash
# from repo root, after dropping the file into assets/
git add assets/hung-yi-lee.jpg
git commit -m "docs: add Hung-Yi Lee portrait to README"
```

If you use a different filename or format (e.g. `.png`), update the `<img src=...>` path in both README files to match.
